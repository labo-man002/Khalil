# Hidden Layers of Truth — طبقات الحقيقة
A self-contained playable Tunisian Darja narrative mystery about **حُسن الظنّ وسوء الظنّ**.

## Play
Open `index.html` in a recent browser. No installation, server, or internet connection required.

## Included
- A connected story with Sami, Adam, Lina, Youssef and Maryam
- 7 consequential choices, confidence input, branching investigation dialogue
- Evidence journal, replay, local save and experimental reflection screen
- Atmospheric CSS 2D scenes and optional synthesized ambient music
- Arabic RTL interface written in Tunisian Darja

## Current limitations
This is a prototype, not a finished long-form game. The 2D environments are CSS illustrations rather than a Phaser character-walking world; the profile scores are fictional gameplay indicators, not validated psychology. All saves are local to the browser.

## Theme
Observation ≠ inference ≠ intention. The story references Qur'an 49:12 (excerpt), without rewarding or penalizing a religious position.
